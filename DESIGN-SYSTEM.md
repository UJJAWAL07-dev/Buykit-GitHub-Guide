# BuyKit GitHub Field Guide — Design System

## Direction
A premium editorial technology handbook, not a SaaS dashboard or generic documentation template. The visual language mixes BuyKit's dark/warm identity with GitHub's developer culture.

## Typography
- Display: Space Grotesk — strong editorial headings.
- Body: DM Sans — readable long-form copy.
- Technical: DM Mono — commands, labels, timestamps and code.

## Palette
- Ink: `#101312`
- Raised ink: `#171B19`
- Paper: `#F5F0E8`
- Paper 2: `#EBE2D8`
- BuyKit wine: `#452829`
- BuyKit warm accent: `#FF8B00`
- Functional green: `#2DA44E`
- Cream: `#F1DDD2`

## Layout
- Comfortable reading width around 760–820px.
- Wider teaching instruments up to 1180px.
- Desktop section rail for navigation.
- Mobile collapses the rail into a full-width menu.
- Visual rhythm alternates prose, diagrams, timelines, simulations and checklists.

## Interaction
- Short, purposeful transitions only.
- No decorative infinite animations.
- Hover states have keyboard/focus equivalents.
- Reduced-motion users receive the same information without non-essential animation.

## Brand
The page uses the official BuyKit logo asset currently published by BuyKit's Insights site: `https://insights.buykit.in/images/buykit-logo.png`.

## SEO
- One H1.
- Semantic H2/H3 hierarchy.
- Canonical article URL.
- Article + BreadcrumbList JSON-LD.
- Open Graph/Twitter metadata.
- Descriptive image alt text.
- Crawlable visible article content.
- Official GitHub/Git references for changing technical details.
